# Coban Pad 12C

![Coban Pad 12C](https://i.imgur.com/PTIaQld.jpeg)
Small ortho keyboard with 9 hotswapable buttons and 1 encoder and 1 horizontal encoder

* Keyboard Maintainer: [RyanDam](https://github.com/RyanDam)  
* Hardware Supported: Coban Pad 12C

Make example for this keyboard (after setting up your build environment):

    make coban/pad12c:default

Flashing example for this keyboard:

    make coban/pad12c:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader:

* **boot button**: Hold the BOOT button on the back of the PCB while plug in usb cable
